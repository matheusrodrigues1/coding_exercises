# Java Stdin and Stdout I

## Plataforma

HackerRank

## Exercício

Java Stdin and Stdout I

## Objetivo

Praticar a leitura de dados pela entrada padrão (`stdin`) e a exibição de resultados na saída padrão (`stdout`) utilizando a linguagem Java.

## Descrição

O exercício solicita a leitura de três números inteiros da entrada padrão e a impressão de cada número em uma nova linha.

## Conceitos Praticados

* Classe `Scanner`
* Entrada de dados pelo teclado (`System.in`)
* Saída de dados (`System.out.println`)
* Variáveis do tipo `int`
* Estrutura sequencial

## Abordagem Utilizada

1. Criar um objeto da classe `Scanner`.
2. Ler os três números inteiros utilizando o método `nextInt()`.
3. Imprimir cada valor em uma linha separada usando `System.out.println()`.

## Conceitos de Programação Desenvolvidos

* Entrada e saída de dados em Java
* Manipulação de variáveis
* Sequenciamento de instruções
* Sintaxe básica da linguagem

## Dificuldade

Easy (Fácil)

## Aprendizados

Este exercício reforça os fundamentos da linguagem Java, especialmente a utilização da classe `Scanner` para receber dados de entrada e o uso de `System.out.println()` para exibir informações no console. Esses conceitos servem de base para problemas mais avançados envolvendo estruturas de decisão, repetição e algoritmos.
